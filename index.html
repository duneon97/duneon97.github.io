SATAN Reborn

An offline-first security auditor for a local code folder, inspired by the 1995 Security Administrator Tool for Analyzing Networks. It scans source code for risky patterns without executing it, installing dependencies, or probing services, and renders its findings as a retro red/green terminal report.

Built by Minh Tuấn Lê as a Kiroween 2026 (Resurrection) project. Requires Python 3.10+, no pip packages.

python -m satan_reborn scan /path/to/local/project --html reports/audit.html
